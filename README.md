# ลานฝึกรถตัก · Wheel Loader Training Sim

เครื่องจำลองฝึกบังคับรถตักล้อยางบนเว็บ เปิด `index.html` ในเบราว์เซอร์ได้ทันที ไม่ต้อง build

**ด่านฝึก**
1. ขับหลบกรวยแบบสลาลม: จับเวลา หักคะแนนเมื่อชนกรวยหรือพลาดประตู
2. ตักให้เต็มบุ้งกี๋ 3 ครั้ง: ชั่งน้ำหนักทุกครั้งบนแท่นชั่ง
3. เทลงกระบะแบบตัว V: วัดดินที่ลงกระบะ ดินหก ระยะห่างจากกระบะ และมุมเข้า
4. ภารกิจ: ตักดินเทลงรถบรรทุกให้ครบ 15 ตันภายใน 6 นาที

**รถขุด (Excavator · คันโยก ISO)**
1. ฝึกคันโยก: แตะเป้า 6 จุดด้วยปลายบุ้งกี๋
2. ขุดร่องตามแนว: ร่องยาว 4 m ลึก 1 m วางดินในกรอบที่กำหนด
3. ขุดบ่อ: ขุดลงในดินแข็งจริงตามหมุด บ่อ 5×5 m ลึก 1.2 m ขอบลาด 1:1 ดินที่ขุดเข้าบุ้งกี๋แล้วยกไปเท (ดินเป็นทรายเม็ดเล็ก เทแล้วกองเป็นเนินทรายจริงบนพื้น) วัดปริมาตรตามแบบ ระดับก้นบ่อ และการขุดเกินแบบ
4. แต่งขอบบ่อ: เกลาขอบลาดที่หนาเกินแบบให้ได้แนว 1:1 (±15 cm) ขุดเกินเส้นได้แต่ถูกหักคะแนน 200 ต่อ m³ (พื้นส่วนที่เกินแบบจะเป็นสีแดง)
5. ขุดใส่รถบรรทุก: ขุดดินแข็งจากพื้นในเขตหมุด (แบบเดียวกับขุดบ่อ) แล้วหมุนป้อมเทใส่รถบรรทุกที่จอดข้างรถขุด ให้ครบ 8 ตันใน 5 นาที
6. ขุดบนทางชัน: ขับขึ้นเนินลาด 20° ขุดดินในเขตหมุดบนไหล่เนิน แล้วเทลงกรอบที่ตีนเนิน มีค่าเสถียรภาพและเสียงเตือน ถ้ายื่นแขนหรือหมุนป้อมพร้อมดินไปทางด้านลาดลง หรือขับเฉียดขอบเนิน รถจะพลิกคว่ำได้ (ลดบุ้งกี๋แตะพื้นเพื่อพยุงรถ)

| รถขุด (ISO) | คีย์บอร์ด | จอยเกม |
|---|---|---|
| แขนออก / เข้า | W / S | ก้านซ้าย ดัน / ดึง |
| หมุนป้อม | A / D | ก้านซ้าย ซ้าย / ขวา |
| บูมลง / ขึ้น | ↑ / ↓ | ก้านขวา ดัน / ดึง |
| หุบ / กางบุ้งกี๋ | ← / → | ก้านขวา ซ้าย / ขวา |
| เดิน / เลี้ยว ตีนตะขาบ | I K / J L | RT LT / LB RB |

**การวัดผลและความพร้อม:** ทุกด่านมีเกณฑ์ผ่านเป็นข้อๆ ต้องผ่านครบทุกข้อ 2 ใน 3 ครั้งล่าสุดจึงนับว่าผ่านด่าน หน้าผลบอกข้อที่ขาดและวิธีฝึก หน้า "ประเมินความพร้อม" สรุปทุกด่านของรถแต่ละประเภท บอกด่านที่ต้องฝึกต่อ และพิมพ์เป็นใบประเมินได้

หน้าปัดมีเกจแรงดันไฮดรอลิก (bar) เขียว → เหลือง → แดงกระพริบเมื่อดันคันโยกค้างจนวาล์วระบายทำงาน เวลาที่ค้างแรงดันเต็มถูกบันทึกและใช้ในเกณฑ์ผ่านทุกด่าน

ผลการฝึกบันทึกในเบราว์เซอร์ตามชื่อผู้ฝึก ดูกราฟพัฒนาการ และส่งออกเป็น CSV ได้จากเมนู

| หงาย / คว่ำบุ้งกี๋ | ← / → | ก้านขวา ซ้าย = หงาย |

## โปรแกรมบน Windows / Mac (ติดตั้งลงเครื่อง เล่นได้โดยไม่ต้องต่อเน็ต)

ดาวน์โหลดได้จากหน้า **Releases** ของ repo (หรือจาก Actions → "Desktop build" → Artifacts)
- `LoaderSim-Setup-x.y.z.exe` ตัวติดตั้ง สร้างไอคอน "ลานฝึกรถตัก" บนเดสก์ท็อป
- `LoaderSim-Portable-x.y.z.exe` ไฟล์เดียว ดับเบิลคลิกเล่นได้เลย ไม่ต้องติดตั้ง
- `LoaderSim-x.y.z-mac.dmg` สำหรับ Mac (Intel และ Apple Silicon) เปิดแล้วลาก LoaderSim ไปไว้ใน Applications
  - ยังไม่ได้ลงนามกับ Apple: ครั้งแรกถ้าขึ้นว่าเปิดไม่ได้ ให้ไปที่ System Settings → Privacy & Security → กด "Open Anyway"
  - ถ้าขึ้นว่า "damaged" ให้เปิด Terminal แล้วพิมพ์ `xattr -cr /Applications/LoaderSim.app` จากนั้นเปิดใหม่

F11 = เต็มจอ · F5 = โหลดใหม่ · ผลการฝึกเก็บในเครื่องนั้น ส่งออก CSV ได้จากเมนูประวัติ

ออกเวอร์ชันใหม่: แก้ `version` ใน `desktop/package.json` แล้ว push tag เช่น `git tag v0.2.0 && git push origin v0.2.0` ระบบจะสร้างตัวติดตั้งและแนบใน Release ให้อัตโนมัติ

รันจากซอร์สโค้ด: `cd desktop && npm install && npm start`

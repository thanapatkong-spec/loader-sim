# ลานฝึกรถตัก · Wheel Loader Training Sim

เครื่องจำลองฝึกบังคับรถตักล้อยางบนเว็บ เปิด `index.html` ในเบราว์เซอร์ได้ทันที ไม่ต้อง build

**ด่านฝึก**
1. ขับหลบกรวยแบบสลาลม: จับเวลา หักคะแนนเมื่อชนกรวยหรือพลาดประตู
2. ตักให้เต็มบุ้งกี๋ 3 ครั้ง: ชั่งน้ำหนักทุกครั้งบนแท่นชั่ง
3. เทลงกระบะแบบตัว V: วัดดินที่ลงกระบะ ดินหก ระยะห่างจากกระบะ และมุมเข้า
4. ภารกิจ: ตักดินเทลงรถบรรทุกให้ครบ 15 ตันภายใน 6 นาที

ผลการฝึกบันทึกในเบราว์เซอร์ตามชื่อผู้ฝึก ดูกราฟพัฒนาการ และส่งออกเป็น CSV ได้จากเมนู

| การบังคับ | คีย์บอร์ด | จอยเกม |
|---|---|---|
| เดินหน้า / ถอย | W / S | RT / LT |
| หักเลี้ยว | A / D | ก้านซ้าย |
| ยก / ลดบูม | ↑ / ↓ | ก้านขวา ดึงกลับ = ยก |
| หงาย / คว่ำบุ้งกี๋ | ← / → | ก้านขวา ซ้าย = หงาย |
| เบรก | Space | A |
| มุมกล้อง | C | |
| เริ่มใหม่ / เมนู / วิธีบังคับ | R / M / H | |

บนมือถือมีก้านบังคับบนจอสองข้าง ดูแผนพัฒนาได้ใน `CLAUDE.md`
